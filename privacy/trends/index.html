ゲーム市場トレンド プライバシーポリシー

株式会社ＴＭソフトウェアエンジニアリング（TM Software Engineering Co., Ltd.）
制定日：2026年10月29日

株式会社ＴＭソフトウェアエンジニアリング（以下「当社」）は、当社が運用する「ゲーム市場トレンド」（以下「本ツール」）における利用者情報の取り扱いについて、以下のとおり定めます。当社が運用する他のアプリケーションの取り扱いは、それぞれのプライバシーポリシーに定めます。

1. 本ツールの概要

本ツールは、ゲーム市場の公開データを収集・集計し、当社の役職員および当社が利用を許可した方が閲覧するための社内向けツールです。一般の利用者向けには提供していません。本ポリシーは、AI アシスタント（Anthropic 社の Claude）から本ツールの MCP サーバー（https://trends.tm-se.co.jp/mcp）へ接続する際に、Google アカウントでログインした利用者の情報の取り扱いを定めます。

2. 取得する情報

本ツールは、利用者が Google の認可画面で許可した範囲（ログインとメールアドレスの確認）で、次の情報を取得します。

  • Google アカウントのメールアドレスと、その確認状態
  • Google アカウントの識別子（ユーザー ID）
  • 本ツールの利用に必要な認可情報（Google のアクセストークン、リフレッシュトークン）

本ツールが利用する認証ライブラリの仕様により、Google から氏名・プロフィール写真を受け取る場合がありますが、本ツールではこれらを利用しません。Gmail、カレンダー、ドライブ、連絡先などの情報にはアクセスしません。

3. 利用目的

  • 利用を許可された方であるかの確認（当社が管理する許可リストとの照合）
  • データの再収集を依頼する機能を使った場合の、依頼者の確認

上記以外の目的には利用しません。広告配信、プロファイリング、データの販売、AI モデルの学習には一切利用しません。

4. 第三者への提供

取得した情報は、法令に基づく場合を除き、第三者に提供しません。AI アシスタント（Anthropic 社の Claude）へ本ツールが返すのはゲーム市場の公開データの集計結果だけであり、利用者のメールアドレス等の情報は送信しません。

5. 保存と安全管理

  • 認可情報は暗号化し、アクセス制限を施した当社管理のサーバーに保存します。通信はすべて HTTPS で暗号化します
  • データの再収集を依頼する機能を使った場合は、依頼者のメールアドレスを依頼の記録に残します。記録は処理待ちの 1 件と処理済みの直近の 1 件だけを保持し、処理済みの記録は次の依頼を処理するときに上書きします
  • 本ツールのサーバーは、利用者の IP アドレスを記録しません

6. 認可情報の削除

  • Google 側でアクセスが取り消されたことを検知した時点（取り消し後に本ツールへの接続があった時点）で、該当する認可情報を削除します
  • ログインから 90 日を経過した認可情報は使用できなくなります。サーバーは起動時と 1 日 1 回、期限を過ぎた認可情報を確認し、Google 側でのアクセス許可の取り消しを試みたうえで、その成否にかかわらず削除します。取り消し後に本ツールへの接続が無い場合も、この期限で削除されます。90 日を経過した後も利用を続ける場合は、AI アシスタントから再度ログインしてください

7. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

Game Market Trends' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. アクセスの取り消し・データの削除の依頼

利用者は、Google アカウントの設定画面（https://myaccount.google.com/permissions）から、いつでも本ツールへのアクセス許可を取り消すことができます。取り消し後の認可情報は第 6 項のとおり削除します。認可情報や再収集の依頼の記録の削除を直ちに希望する場合は、第 10 項のお問い合わせ先までご連絡ください。

9. 本ポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。変更後の内容は本ページに掲載した時点から効力を生じます。ただし、Google から取得した情報を新たな目的で利用する場合は、その利用を始める前に利用者へ通知し、同意を得ます。

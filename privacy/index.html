プライバシーポリシー

株式会社ＴＭソフトウェアエンジニアリング（TM Software Engineering Co., Ltd.）
制定日：2026年10月14日

株式会社ＴＭソフトウェアエンジニアリング（以下「当社」）は、当社が運用するアプリケーション「TM-SE Workspace Connector」（以下「本アプリ」）における利用者情報の取り扱いについて、以下のとおり定めます。

1. 本アプリの概要

本アプリは、当社および当社代表者が自ら管理する Google アカウントのメール・カレンダー情報を、当社が利用する AI アシスタント（Anthropic 社の Claude）から参照・整理するための社内向けツールです。一般の利用者向けには提供していません。

2. 取得する情報

本アプリは、利用者が Google の認可画面で許可した範囲で、次の情報にアクセスします。

  • Gmail：メールの件名・本文・送信者などのメッセージ情報、ラベル、下書き
  • Google カレンダー：カレンダーの一覧、予定の内容、空き時間の情報
  • 認可に必要な Google アカウントのメールアドレス

3. 利用目的

  • 受信メールの検索・要約・優先度の整理
  • 返信の下書き作成およびラベルによる整理（メールの送信は行いません）
  • 予定の確認および管理

上記以外の目的には利用しません。広告配信、プロファイリング、データの販売には一切利用しません。

4. 第三者への提供

取得した情報は、利用者自身の指示に基づき AI アシスタント（Anthropic 社の Claude）へ処理のために送信される場合を除き、第三者に提供しません。ただし、法令に基づく場合はこの限りではありません。

5. 保存と安全管理

本アプリは、Google API へアクセスするための認可情報（アクセストークン等）を、当社が管理するサーバー上にアクセス制限を施して保存します。メールやカレンダーの内容をサーバーに恒常的に保存することはありません。通信はすべて HTTPS で暗号化します。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

TM-SE Workspace Connector's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. アクセスの取り消し・データの削除

利用者は、Google アカウントの設定画面（https://myaccount.google.com/permissions）から、いつでも本アプリへのアクセス許可を取り消すことができます。取り消し後、当社サーバー上の該当アカウントの認可情報は速やかに削除します。

8. 本ポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。変更後の内容は本ページに掲載した時点から効力を生じます。
